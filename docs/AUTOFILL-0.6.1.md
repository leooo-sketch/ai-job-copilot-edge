# 0.6.1 下拉框修复

代码确认的缺口：旧版 Ant Design 选项类名及选中值类名缺失；已打开的关联下拉框被再次点击关闭；本科/大学本科等同义文字不完整；培养方式和学习形式错误共用字段。

本版修复以上问题，并补充学科、是否统招字段。培养方式不从全日制推断，统招也不从学校或学历推断。请在资料库中按实际情况补充。排名支持前5%/Top 5%等明确同义表达，不将绝对名次或不明分母猜成百分比。

验证：32 项自动化测试通过，使用合成 DOM；未连接用户当前海信页面，不能确认其实际前端框架，也不能宣称该网站全部填写成功。特殊日期面板、级联地区和虚拟滚动选项仍可能需要手动操作。本次没有改动已安装插件或提交真实申请。

升级：先导出 JSON 备份，将包内文件覆盖到当前加载的插件目录，在原扩展上点重新加载，再刷新招聘网页。不要先卸载或另外加载一个新目录，以免更换扩展 ID 后看不到旧资料。保留原资料存储键、旧字段和模型配置；新字段默认为空。
